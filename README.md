# Сайт X-Lab

Простой статический одностраничный сайт проектного практикума. Без сборки, без сервера — обычные HTML/CSS/JS.

## Структура

```
index.html              — вся страница (секции сайта)
assets/css/style.css    — стили, цвета курса заданы в начале файла (:root)
assets/js/script.js     — подгружает карточки проектов из data/projects.json
assets/img/             — логотип, фото
assets/img/projects/    — фотографии проектов прошлых лет
data/projects.json      — список проектов прошлых лет (см. ниже)
```

## Как добавить проект прошлых лет

Это единственное, что нужно делать регулярно.

1. Положите фото проекта в `assets/img/projects/` (например, `moy-proekt.jpg`).
2. Откройте `data/projects.json` и добавьте новый блок в список (не забудьте запятую после предыдущего блока):

```json
{
  "title": "Название проекта",
  "year": "2024/2025",
  "category": "Базовая робототехника",
  "description": "Пара предложений о том, какая была задача и что получилось.",
  "image": "assets/img/projects/moy-proekt.jpg"
}
```

3. Сохраните файл — новая карточка появится на сайте автоматически, ничего в HTML менять не нужно.

Чтобы убрать проект — удалите его блок из `data/projects.json`. Чтобы поменять порядок — переставьте блоки местами (сверху = первый на сайте).

## Как заменить логотип и цвета

- Логотип: замените файл `assets/img/logo.svg` на свой (тот же путь и имя, либо поменяйте путь в `index.html`, где он используется дважды — в шапке и в hero-блоке).
- Цвета курса заданы в самом начале `assets/css/style.css`:

```css
:root {
  --red: #e8262a;
  --black: #141414;
  ...
}
```

Поменяйте `--red` на точный HEX из брендбука — вся палитра сайта завязана на эту переменную.

## Как посмотреть сайт локально

Открыть `index.html` двойным кликом не получится в полной мере — список проектов подгружается через `fetch`, а браузеры блокируют это для файлов, открытых напрямую (`file://`). Нужен локальный сервер:

```bash
cd x-lab
python3 -m http.server 8000
```

и открыть `http://localhost:8000` в браузере.

## Публикация на GitHub Pages

1. В настройках репозитория: **Settings → Pages → Source** — выбрать ветку (например, `main`) и папку `/ (root)`.
2. Через 1–2 минуты сайт будет доступен по адресу вида `https://<username>.github.io/<repo>/`.
3. Дальше любое изменение, запушенное в эту ветку, автоматически обновляет сайт — ничего дополнительно собирать не нужно.
