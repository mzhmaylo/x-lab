# Сайт X-Lab

Простой статический одностраничник проектного практикума X-Lab. Без сборки, без сервера — обычные HTML/CSS/JS.

- `index.html` — вся страница
- `assets/css/style.css` — стили, переменные цветов в начале файла (`:root`)
- `assets/js/script.js` — интерактив: скролл-анимации, счётчики, фильтры и карусель проектов, логотипы партнёров
- `data/projects.json` — проекты прошлых лет
- `data/organizers.json` — логотипы и описания организаторов
- `data/customers.json` — логотипы заказчиков
- `data/videos.json` — видео-интервью со студентами

## Как добавить проект

Положить фото в `assets/img/projects/`, добавить блок в `data/projects.json`:

```json
{
  "order": 11,
  "title": "Название проекта",
  "year": "2024/2025",
  "category": "Робототехника",
  "description": "Пара предложений о задаче и результате.",
  "image": "assets/img/projects/moy-proekt.jpg"
}
```

- `category` — становится кнопкой-фильтром по категориям, собирается автоматически из того, что есть в файле. Можно писать любые свои категории.
- `year` — становится кнопкой-фильтром по годам, тоже собирается автоматически.
- `order` — число, определяющее порядок на сайте (меньше — раньше). Необязательное поле: если не указать, проекты выстроятся в том порядке, в котором идут в файле.

Проекты показываются каруселью по 8 карточек (2 ряда × 4) со стрелками пролистывания — при 20–30 проектах пролистывание работает само, ничего дополнительно настраивать не нужно.

## Как добавить заказчика

Заказчики показываются просто логотипами в горизонтальной прокрутке (стрелки появляются, когда логотипы не помещаются в один экран).

1. Положите логотип (лучше в белом цвете, на прозрачном фоне — PNG или SVG) в `assets/img/customers/`.
2. Добавьте запись в `data/customers.json`:

```json
{
  "name": "Название компании",
  "logo": "assets/img/customers/company.png"
}
```

## Как добавить организатора

У организаторов, в отличие от заказчиков, ещё показывается короткое описание — 2–3 предложения о том, кто это. Порядок на сайте — тот же, что и в файле `data/organizers.json`.

1. Положите логотип (белый, на прозрачном фоне) в `assets/img/organizers/`.
2. Добавьте запись в `data/organizers.json`:

```json
{
  "name": "Название организации",
  "logo": "assets/img/organizers/company.png",
  "description": "Пара предложений о том, кто это и при чём здесь X-Lab."
}
```

Логотипы organizers и customers показываются на тёмной плашке, поэтому светлый/белый вариант — то, что нужно.

Сейчас в обоих файлах — логотипы-заглушки (текст на прозрачном фоне). Замените файлы в `assets/img/organizers/` и `assets/img/customers/` на реальные, оставив те же имена — тогда в JSON ничего менять не придётся. Если добавляете нового партнёра (а не заменяете существующего) — нужно и файл логотипа добавить, и запись в JSON.

## Как добавить видео-интервью

Раздел «Интервью со студентами» (`id="videos"`) — тоже горизонтальная карусель со стрелками, карточки ведут на видео по ссылке (например, ролик из группы ВКонтакте — просто обычная ссылка на страницу с видео, открывается в новой вкладке).

1. Положите превью (лучше 16:9) в `assets/img/videos/`.
2. Добавьте запись в `data/videos.json`:

```json
{
  "order": 5,
  "title": "Название видео",
  "url": "https://vk.com/video-000000000_000000000",
  "thumbnail": "assets/img/videos/moe-video.jpg"
}
```

`order` работает так же, как у проектов — определяет очерёдность, необязательно. Сейчас там 4 заглушки со ссылками на `#videos` — замените `url` на настоящие ссылки на видео и превью на реальные кадры.

## Заказ услуг у CML / FORMA

Блок «Работаете не только со студентами?» в секции организаторов (`id="hire"`) — кнопки заказа у CML и FORMA. Сейчас обе ведут на `mailto:zhmaylo.m@compmechlab.ru` с разными темами письма. Если появятся отдельные email или сайты — поменяйте `href` у соответствующих кнопок в `index.html`.

Кнопка «Заказать коммерческий проект» в блоке «Готовы присоединиться к X-Lab?» ведёт туда же (`#hire`).

## Блок «История»

Текст — в `index.html`, секция `id="history"`. Три фотографии (пропорции 4:3), расположены в столбик — файлы `assets/img/history-1.png`, `history-2.png`, `history-3.png`. Сейчас там заглушки, замените их на реальные фото с теми же именами (можно другой формат, например `.jpg` — тогда поправьте расширение и в `index.html`).

## Шрифт

Сайт использует Golos Text (Google Fonts, полная кириллица), подключается через `<link>` в `<head>` — интернет для загрузки шрифта нужен посетителю сайта, локально ничего хранить не надо. Если захотите сменить шрифт — поменяйте ссылку на Google Fonts в `index.html` и значение `font-family` в начале `assets/css/style.css` (`body`).

## Карта в контактах

В блоке контактов — встроенная карта Google Maps (`iframe` без API-ключа, по текстовому адресу). Если адрес изменится, поправьте `q=` в `src` у `iframe` в секции `id="contacts"`.

## Как посмотреть сайт локально

Открыть `index.html` двойным кликом не получится в полной мере — список проектов и логотипы партнёров подгружаются через `fetch`, а браузеры блокируют это для файлов, открытых напрямую (`file://`). Нужен локальный сервер:

```bash
cd x-lab
python3 -m http.server 8000
```

и открыть `http://localhost:8000` в браузере.

## Публикация на GitHub Pages

1. В настройках репозитория: **Settings → Pages → Source** — выбрать ветку (например, `main`) и папку `/ (root)`.
2. Сайт доступен по адресу:

```
https://mzhmaylo.github.io/x-lab/
```

3. Дальше любое изменение, запушенное в эту ветку, автоматически обновляет сайт — ничего дополнительно собирать не нужно.
