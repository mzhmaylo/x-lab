# Сайт X-Lab — новая версия (v2)

Второй, отдельный от корневого сайта, одностраничник. Живёт в этой папке, ничего не разделяет с корневым сайтом — можно менять как угодно, не затрагивая старую версию.

- `index.html` — вся страница
- `assets/css/style.css` — стили, переменные цветов в начале файла (`:root`)
- `assets/js/script.js` — интерактив: скролл-анимации, счётчики, фильтры и карусель проектов, логотипы партнёров
- `data/projects.json` — проекты прошлых лет
- `data/organizers.json` — логотипы организаторов
- `data/customers.json` — логотипы заказчиков

## Как добавить проект

Положить фото в `assets/img/projects/`, добавить блок в `data/projects.json`:

```json
{
  "order": 11,
  "title": "Название проекта",
  "year": "2024/2025",
  "category": "Робототехника",
  "description": "Пара предложений о задаче и результате.",
  "image": "assets/img/projects/moy-proekt.jpg"
}
```

- `category` — становится кнопкой-фильтром по категориям, собирается автоматически из того, что есть в файле. Можно писать любые свои категории.
- `year` — становится кнопкой-фильтром по годам, тоже собирается автоматически.
- `order` — число, определяющее порядок на сайте (меньше — раньше). Необязательное поле: если не указать, проекты выстроятся в том порядке, в котором идут в файле.

Проекты показываются каруселью по 8 карточек (2 ряда × 4) с стрелками пролистывания — при 20–30 проектах пролистывание работает само, ничего дополнительно настраивать не нужно.

## Как добавить организатора или заказчика

Логотипы organizers и customers — из своих JSON-файлов, у обоих одинаковый формат. Например, чтобы добавить нового заказчика:

1. Положите логотип (лучше в белом цвете, на прозрачном фоне — PNG или SVG) в `assets/img/customers/`.
2. Добавьте запись в `data/customers.json`:

```json
{
  "name": "Название компании",
  "logo": "assets/img/customers/company.png"
}
```

Для организаторов — то же самое, но файл `data/organizers.json` и папка `assets/img/organizers/`. Логотипы показываются на тёмной плашке, поэтому светлый/белый вариант логотипа — то, что нужно.

Сейчас в обоих файлах — логотипы-заглушки (просто текст на прозрачном фоне). Замените файлы в `assets/img/organizers/` и `assets/img/customers/` на реальные, оставив те же имена — тогда в JSON ничего менять не придётся.

## Блок «История»

Текст — в `index.html`, секция `id="history"`. Две фотографии (пропорции 4:3) — файлы `assets/img/history-1.jpg` и `assets/img/history-2.jpg`. Сейчас там заглушки, замените их на реальные фото с теми же именами.

## Карта в контактах

В блоке контактов — встроенная карта Google Maps (`iframe` без API-ключа, по текстовому адресу). Если адрес изменится, поправьте `q=` в `src` у `iframe` в секции `id="contacts"`.

## Локальный просмотр

```bash
cd x-lab
python3 -m http.server 8000
```

Открыть `http://localhost:8000/v2/`.

## Адрес после публикации

Сайт лежит в подпапке того же репозитория, поэтому отдельно включать GitHub Pages не нужно — он появится по тому же домену, что и основной сайт, но с `/v2/` в конце:

```
https://mzhmaylo.github.io/x-lab/v2/
```
